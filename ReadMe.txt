Le fichier qui liste les étudiants doit contenir les colonnes : 
N°, NOM, PRENOM, REDOUBLANT, UEX

Les valeurs possible pour l'UEX sont : 
BIO303, BIO303 VALIDÉ, BIO304, BIO304 VALIDÉ, BIO305, BIO305 VALIDÉ

Le nom des colonnes doit être sur la première ligne.

 


Première étapes :
Prends le fichier qui liste les étudiants et celui qui liste les équipe.
Renvois deux fichier pour identifier les étudiants sur la liste des équipes.
